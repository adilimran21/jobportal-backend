# Job Portal Backend

Backend REST API for a Job Portal application built with Java and Spring Boot.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Features

- User Registration & Login
- JWT Authentication
- Role-Based Authorization
- Candidate Profile Management
- Recruiter & Company Management
- Job Management
- Job Search & Filtering
- Job Applications
- Saved Jobs
- Application Tracking
- Notifications & Email
- Job Recommendations
- Admin Management & Reports

## Run Locally

Create a MySQL database named:

```sql
CREATE DATABASE jobportal;

Configure these environment variables:

DB_USERNAME
DB_PASSWORD
JWT_SECRET
MAIL_USERNAME
MAIL_PASSWORD

Run the application:

mvn spring-boot:run

Backend runs on:

http://localhost:8080
